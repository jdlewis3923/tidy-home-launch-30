Lawn size = square feet of GRASS only (never house, driveway, walkways, patio, pool, decking).
Small ≤3,000 · Standard 3,000–7,000 · Large 7,000–12,000 (inclusive at top). Over 12,000 = custom quote, never self-bookable.
Never ask customers to measure. Every lawn reservation is verified from aerial imagery before converting.
Size-up: customer told before first visit and must confirm; decline cancels (never downgrade). Size-down: automatic + notice.
Founding members keep their own rate card on size changes. Never absorb an oversized yard. Prices/pay unchanged.
Stripe lawn price metadata: contractor_pay per cadence from canon (monthly 18/26/40), budget_hours 0.6/0.9/1.5.

- The old $30 extra-large lawn surcharge is removed (confirmed by Justin); the bands replace it.
- Pro pay never moves with cadence: lawn $18/$26/$40, cleaning $56/$76/$112 on every cadence. Cadence discounts come out of Tidy's margin.
- Lawn added from an existing account and later size corrections follow the same verify/confirm rules as reservations.
